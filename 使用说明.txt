声线实验室 · 使用说明（AI 声音克隆版）

一、第一次使用
1. 双击“安装AI克隆引擎.bat”，等它跑完（会下载约 1GB 的模型和环境，只需一次）。
   - 网络下不动模型就再运行：python tools\setup_ai.py --mirror
   - 没有 NVIDIA 显卡也可以装：python tools\setup_ai.py --cpu（会慢很多）
2. 双击“启动声线实验室.bat”，浏览器会自动打开 http://localhost:8000/
3. 右上角显示“AI 克隆”就说明引擎就绪；第一次合成会自动把模型读进显卡，约 20–40 秒。

二、克隆一个音色
1. 左侧“导入音频 / 视频”：可以直接选 mp4，程序会自动取里面的音轨。
2. 页面会自动挑出最适合克隆的 3–8 秒片段，并在波形上高亮。
   - “候选片段”里可以换别的片段；
   - “试听推荐片段”先听一下，确认是单人、没有背景音乐、没有杂音。
3. 参考文字会自动识别（“自动识别”按钮可重试）。
   ★ 这段文字必须和音频里说的内容一致，否则克隆出来的音色会跑偏，这是最常见的原因。
4. 给音色起名，点“建立克隆音色”。音色会保存到左侧“我的克隆音色”，下次直接点就能用。

三、克隆朗读
1. 点左侧音色 → 在“用这个音色朗读”里输入文字。
2. “生成朗读”会按句合成再拼接，长文也可以（进度条会动）。
3. 试听满意后“导出 WAV”，或去“视频解说剪辑”页给视频配音。

四、微调（可选）
- 音调：不改语速地升降调（PSOLA，不会变机器人）；
- 共振峰：改变声带“大小”，女声化/更低沉主要靠它；
- 语速、明亮度、厚度、存在感、气声、空间感、齿音抑制：都在本机音频处理里完成。
- 风格：自然克隆 / 播音清晰 / 温暖厚实 / 低沉磁性 / 轻柔气声 / 女声化 / 少女感 / 搞怪萌音。

五、视频解说剪辑
1. 导入视频 → 点“克隆音色生成解说” → 选音色、输入解说词、选语气 → 生成。
2. 生成的解说会放到“我的解说”轨道，可以调音量、和背景音乐一起导出 WebM。

六、显存与性能（GTX 1050 Ti 4GB）
- 使用蒸馏版 ZipVoice（8 步），单块参考+生成控制在 12 秒内，显存不够会自动拆得更小重试。
- 如果还爆显存：编辑 voice/config.json，把 max_duration 改 8，dtype 改 "fp16"，再重启服务。
- 生成时尽量不要同时跑游戏/剪辑软件；不生成时模型会尽量释放显存。

七、隐私与合规
- 参考音频、音色、文字全部保存在本机 data 目录，不会上传。
- 请只使用本人声音或已获得明确授权的声音，不要用于伪造他人身份或误导性内容。

八、常见问题
- 显示“未安装 PyTorch / 未找到模型”：重新运行安装脚本。
- 声音不像：换更干净的 3–6 秒片段、核对参考文字、参考音频不要带音乐和混响。
- 自动识别不可用：pip install faster-whisper，或手动填写参考文字。
- 页面打不开：用启动脚本启动，或在项目目录执行 .venv\Scripts\python.exe voice_server.py
